# 领域文档

本仓库采用 single-context。

## 探索前读取

- 根目录 `GLOSSARY.md`：项目领域术语。
- `docs/adr/`：只读取与当前工作相关的架构决定。

文件或目录不存在时直接继续，不将缺失视为错误，也不建议提前创建。
`domain-modeling` 会在术语或决定明确后按需记录；不预先创建空 ADR 或示例 ADR。

## 使用术语

在 issue 标题、设计讨论、重构建议、假设和测试名称中，使用 `GLOSSARY.md` 定义的术语，避免采用其中明确排除的同义词。

需要的概念尚未定义时，先判断是否误用了项目语言；确有缺口则交由 `domain-modeling` 澄清。
词汇表只记录领域定义，不承载实现细节或功能规范。

## ADR 冲突

若建议与现有 ADR 冲突，明确指出 ADR 编号和重新讨论的理由，不静默覆盖既有决定。
