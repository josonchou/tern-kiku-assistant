# Tern worktree 管理

Status: claimed

## 目标与来源

将 Herdr worktree 管理行为迁移到现有 Tern 插件，不复制 Herdr workspace 界面。产品决定来自 `docs/design.md` 的“Herdr worktree 管理行为迁移”；本文件及关联 tickets 是实施和完成状态的入口。用户已调用 implement-spec 授权实施，并批准建立初始 Git 基线。

## 已确认范围

1. 仅本机 macOS/Linux。当前仓库全部 Git 登记的 worktree 均可发现，包括 Git、lazygit、Herdr 创建的；不依赖插件创建记录。主工作树可打开，不可移除。
2. 一个 worktree 对应一个命名标签页，内部允许多个 pane；不改为独立 session。打开时优先复用当前窗口可见会话中的有效绑定；多个候选让用户选择，无候选才新建，不自动合并或关闭。
3. 关闭工作环境、移除工作树、删除分支是三个不同概念。插件不删除分支，不自动 merge、push 或 fetch。
4. 关闭只针对选定的绑定标签页。运行中命令、未保存内容、无法确认安全的 pane 均拒绝关闭；安全检查通过后仍需确认，不提供强制关闭。确认后执行前再次检查，状态变化时保留环境。
5. 移除前必须先关闭当前窗口可见会话中仍使用目标工作树的环境，包括浮动或 parked pane。不能为了移除而自动结束程序。外部终端、其他工具或不可见窗口的使用情况需要用户确认。
6. 正常移除拒绝已修改、未跟踪、忽略文件，以及没有本地／远程分支或标签保护的 Detached 提交。主工作树、锁定、prunable／路径失效、身份不符或状态未知的对象不可移除。
7. 独立危险入口允许明确丢弃本地内容或未受保护的 Detached 提交。必须展示受影响的文件／提交风险，要求重新输入完整目标路径并明确确认无外部使用；输入不符或取消不得操作。它不能越过主工作树、锁定、使用中和身份／状态未知的保护；不 unlock、不使用双重 --force。
8. 所有危险操作在最终确认后重读 worktree 登记、目标仓库身份、HEAD／分支、安全状态和可见使用者。预览后目标身份、内容风险列表或保护状态变化时取消本次操作，要求重新审阅，不用重试自动越过保护。Git 仍是最终并发保护；失败保留现场，不自动 rm、prune、删分支或强制重试。
9. 保留现有创建三种模式、基准分支选择、Ctrl+B → Shift+G、lazygit 对齐目录规则、defaultPath、自定义路径，以及创建后打开失败时保留 worktree 的行为。
10. 新增命令 `plugin.kiku.manage_worktrees`，标题“Kiku: 管理 Git worktree”，使用原生 picker/prompt。新增字符串配置 `manageKeybinding`，空值默认不绑定。创建与管理共享一个窗口内流程锁，各级 Esc 取消不改变 Git 或关闭环境。

## 身份与安全约束

- 以 Git 实际仓库身份、登记路径、当前 pane/tab/session/host 关系识别对象；不以 tab 标题、分支名或简单字符串前缀作为唯一身份。
- 子目录和符号链接来源须能归属到正确 worktree；同名分支／相似路径／远程主机上的同名路径不能误匹配。
- 候选发现不等于获得关闭权限。只有用户选择的绑定标签页才是关闭对象，不能扫描并自动关闭所有 cwd 相同的标签页。
- 关闭前检查绑定标签页的全部 tiled/floating pane；未知类型、缺失安全字段、未保存工具状态、忙碌命令均保守拒绝。不能把没有 dirty 字段当作干净。
- 错误应说明拒绝原因与可执行的手动处理方式。安全确认默认选取消；成功显示目标路径或环境。
- 不声称跨窗口原子去重、检测所有外部进程或恢复已关闭程序。无需新增远程执行、布局模板、复制环境变量或初始化脚本。

## 验收与测试接口

用户已确认 TDD seams：真实 Tern 命令／原生选择框，以及隔离 Git 仓库、文件内容、refs 和工作树登记等用户可观察结果。使用已有 Python 驱动和 Tern 原生 Luau，不 mock 宿主或 Git。

- 外部创建的工作树可发现、打开；重复打开不新增 tab；多个候选明确选择；来源子目录／别名路径不产生错误归属。
- 关闭正确的已绑定环境而保留工作树和分支；忙碌、未保存、未知、安全状态变化以及取消均保留所有相关 pane。
- 正常移除仅删除干净、未使用、非主工作树且身份已确认的 checkout，保留分支与其他工作树；危险内容和所有不可越过保护都得到拒绝。
- 强制入口在路径确认正确且保护检查通过时才移除；取消、错路径、确认期间状态变化不产生删除；危险 Detached 提交可显式放弃，有分支保护的 Detached 可正常移除。
- 创建流程的已有回归继续通过；管理快捷键独立可配置且默认无绑定。
- 原生界面截图和真实 Git 状态验证作为烟测证据；不执行浏览器自动化。
